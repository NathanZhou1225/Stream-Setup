## 适用场景

用户在对话中涉及以下意图时触发本 Skill（匹配意图，不要求精确措辞）：

| 用户说什么（示例，不限于此） | 触发入口 | 阶段 |

## 全流程（五阶段门禁）

内容生成严格遵循阶段顺序，**禁止跳步**：
数据层 → topic_picking → outline_refining → script_refining → finalized

### 阶段 1 · 行情快照（纯拉数）

用户要行情/热点/市场数据，**未进入开稿**时：
python skills/streamy-content-gen/scripts/query_market_facts.py --sources market,news,social --summary-only

- 默认走云端 API + 本地 Router/Rewriter
- 缓存优先；需刷新加 --force-refresh
- 返回的 markdown_summary **全文原样展示**，禁止删段、禁止缩减为表格

**定向简报**（只看某方向，禁止贴全量）：
python skills/streamy-content-gen/scripts/query_direction_brief.py --direction "方向关键词"

### 阶段 2 · 选题开稿（topic_picking）

用户给出方向并要求开稿时，**必须先 preflight**：
python scripts/stream_gen_workflow_helper.py start-topic --direction "用户给出的方向"
- 输出 topic_payload，含 3 个候选方向 + 预计算证据包
- **展示三候选，等用户选号**
- **禁止同轮写大纲/逐字稿**

### 阶段 3 · 选题确认 + 风格绑定

用户选定候选后：
python scripts/stream_gen_workflow_helper.py apply-choice --draft <DID> --choice <N>

**风格绑定（进大纲前必须完成）**：
展示所有稿件类型 × 风格组合
python scripts/stream_gen_workflow_helper.py list-profile-options
用户选定后一步绑定
python scripts/stream_gen_workflow_helper.py bind-profile --draft <DID> --content-type <type> --style-id <UUID>

- 不得用"默认风格"跳过
- 必须同时确认内容类型 + 风格，不可只选其一

### 阶段 4 · 大纲撰写（outline_refining）

风格绑定完成后：
python skills/streamy-content-gen/scripts/draft_manager.py schema --stage outline_refining --inject-prompt-template --json
python skills/streamy-content-gen/scripts/draft_manager.py update --draft <DID> --stage outline_refining --payload-file <json> --inject-evidence-level minimal

### 阶段 5 · 逐字稿撰写（script_refining）

大纲落盘后：
python skills/streamy-content-gen/scripts/draft_manager.py schema --stage script_refining --inject-prompt-template --json
python skills/streamy-content-gen/scripts/draft_manager.py update --draft <DID> --stage script_refining --payload-file <json> --inject-evidence-level full

### 阶段 6 · 定稿归档（finalized）
python skills/streamy-content-gen/scripts/draft_manager.py finalize --draft <DID> --auto-refine --min-context-reset
